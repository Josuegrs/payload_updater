# PS5 Payload Catalog

Public payload catalog for **PS5 Payload Manager**. It includes 52 projects, their download links, and their icons.

## Disclaimer

This catalog links to third-party projects. I do not create or maintain these projects, and I am not responsible for payload failures, damage, data loss, or any other issues resulting from downloading or using them. Use them at your own risk.

## Files

- [`payloads-extra.json`](payloads-extra.json): catalog to import into PS5 Payload Manager.
- [`icons.json`](icons.json): project icons.
- [`projects.json`](projects.json): list of included projects.
- [`update_payloads.py`](update_payloads.py): updates the catalog from official releases.

## Add the Catalog to PS5 Payload Manager

1. Open the PS5 Payload Manager dashboard.
2. Open **Settings** and enable **Extra Catalogs**.
3. Go to **Settings** (gear icon) and select **Manage Sources**.
4. Select **Add Source**, paste the catalog URL below, and select **Add**.
5. Payload Manager will validate the URL and add the catalog to your sources.

https://raw.githubusercontent.com/Josuegrs/payload_updater/main/payloads-extra.json

## Updating

The workflow can be started manually. It finds the latest release for each project and updates `payloads-extra.json` with its version, date, link, and SHA-256 hash.
